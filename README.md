# Vong Quay Li Xi Tet 2026

Web ReactJS giao dien Tet 2026, quay li xi 3 luot/nguoi, luu localStorage, co bang vang + hieu ung.

## Chuc nang chinh

- Vong quay menh gia tu `10k` den `150k`.
- Menh gia cang cao, xac suat cang thap.
- Popup nhap ten nguoi choi bang SweetAlert2.
- Moi nguoi choi toi da `3` luot quay.
- Luu lich su quay vao localStorage.
- Co hieu ung confetti, am thanh va bang vang xep hang.

## Cai dat

```bash
npm install
```

## Chay local

```bash
npm run dev
```

Frontend: `http://localhost:5173`

## Build

```bash
npm run build
```
